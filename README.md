# MiniApps
## What is it?
A collection of single-purpose applications that are designed to be simple and easy to use. These range from simple
random number generator or choice picker to more complex applications like a password generator or a job application tracker with cloud account support (in development). 

## Why?
Whenever I need a tool and I do not like what I find online, I make my own. I decided to share them with the world in case someone else finds them useful. Additionally, it also allows me to improve my web development skills.

Using one theme allows me to reuse code and design elements across applications, making it easier to ship out new features, completely eliminating the initial overhead of setting up a new project.

## Technologies
* Language: [TypeScript](https://www.typescriptlang.org/)
* UI Library: [React](https://reactjs.org/)
* Routing: [Tanstack Router](https://tanstack.com/router/latest)
* Build Tool: [Vite](https://vitejs.dev/)
* Styling: [Tailwind CSS](https://tailwindcss.com/)
* Components: [Shad CNC](https://ui.shadcn.com/)


## Applications
* **Future Predictor** : A simple application that has a hidden input not accesed through the nav menu where you can write stuff about the person that is going to enter the details next. <br> I mostly did this because of a childhood memory where I saw a similar application and I wanted to recreate it. It is going to be removed in the future and replaced by more useful tools.

* **Random Generator** : Generate a random number in a given range or pick a random choice from a list that you provide.


## Future Applications
* **Password Generator** : Generate a random password with options to include numbers, special characters, and uppercase letters.
* **Job Application Tracker** : Track job applications with cloud account support. This will allow you to save your applications and access them from any device.
* **To-Do List** : A simple to-do list application that allows you to add, remove, and mark tasks as complete.

## How to access the applications?
Go to [my website](https://miniapps.klejdis.com) and select the application you want to use from the navigation menu.
